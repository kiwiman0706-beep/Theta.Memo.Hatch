# GTD・アイゼンハワーマトリクス・入れ子・マインドマップ（0.2.0）

ふつうのメモはそのまま。**「✓（タスク）」を押したメモ**と、**印を付けたチェックリストの行**が GTD の対象になります。全部 Obsidian で読めるMarkdownのままです。

## GTD のリスト

メニューの「GTD」に並びます。新しいメモをそのリストで作ると、そのリストに入ります。

| リスト | `gtd:` | 使い方 |
| --- | --- | --- |
| 📥 受信箱 | `inbox` | 思いついたら何でも。あとで「整理する」 |
| ▶ 次にやる | `next` | すぐ取りかかれる1つの行動 |
| ⏳ 待ち | `waiting` | 人に任せた・返事待ち（`waiting_for:` に相手） |
| 📅 予定 | `scheduled` | 日にちが決まっている（`due:`） |
| 📁 プロジェクト | `project` | 2つ以上の行動が要るもの。行動は**子メモ**か、本文のチェックリスト |
| 💭 いつか | `someday` | いつか・多分 |
| 📚 資料 | `reference` | 行動は要らないが残す |
| ✅ 完了 | `done` | 終わったもの（`done:` に日時）。メモの一覧からは隠れます |

**整理する**（受信箱のメモで）：「行動が必要？」→「2分で終わる？」→「1回で終わる？」→「誰がやる？」→「日にちは決まっている？」の順に答えると、振り分けまで済みます。プロジェクトにするときは最初の行動を書けば子メモ（次にやる）ができます。受信箱の上の「先頭から整理する」で続けて処理できます。

**週次レビュー**（メニュー）：受信箱の件数、期限切れ、**次の行動が無いプロジェクト**、待ち、いつか、この1週間の完了を一覧にして、そこへ飛べます。

**状況**（`contexts:`）：@家・@PC・@電話 のように、どこで・何でやるか。

## アイゼンハワーマトリクス

メニュー →「マトリクス（重要×緊急）」。

| | 緊急 | 緊急でない |
| --- | --- | --- |
| **重要** | 今すぐやる | 計画してやる |
| **重要でない** | 任せる・手早く | やめる・あとで |

- 載るもの：「次にやる・待ち・予定・プロジェクト」のメモ、それらのメモの中の未完了のチェックリスト、そして**どのメモでも** ★重要・⚡緊急・📅期限 を付けたチェックリストの行。
- **期限が2日以内（または過ぎた）なら自動で緊急**として扱います（ファイルには書きません）。
- 行を**長押しして別の欄へドラッグ**、または「⇄」で移動。チェックで完了。各欄の「＋」でその欄の行動を作成。

### ファイルでの形

メモ（frontmatter）：

```yaml
gtd: next
important: true
urgent: false
due: 2026-11-01
contexts: ['@PC']
waiting_for: 山田さん
done: 2026-10-30T10:00:00.000+09:00
```

チェックリストの行（Obsidian の **Tasks プラグイン**と同じ書き方。Obsidian でもそのまま検索・集計できます）：

```markdown
- [ ] 見積書を送る #重要 #緊急 📅 2026-11-01
- [x] 電話した #重要 ✅ 2026-10-29
```

## 入れ子

- **子メモ**：メモの「⋮」→「＋子メモを作る」、「親メモを選ぶ（入れ子にする）」、チェックリストの行の「⋯」→「子メモにする」。子メモは親の中（本文の下）に並び、メモの一覧には出ません（検索では見つかります）。子メモを開くと上に親への道しるべ、閉じると親に戻ります。何段でも入れ子にできます。
- ファイルでは `parent: <親のid>` と、Obsidian 用に `up: "[[親のファイル名]]"`（Breadcrumbs プラグインと同じ項目名）。**Obsidian で `up: "[[親]]"` だけ書いたノートも、同期で子メモとして取り込みます。** 親の名前を変えると子の `up` も書き直します。
- **アウトライン**：本文の箇条書きは「⇥ ⇤」（書式バー）や Tab キーで何段でも入れ子に。チェックリストは左右にスワイプ、または「⋯」→「1段下げる／上げる」。

## マインドマップ

- メモの「⋮」→「マインドマップで見る」。タイトルが中心、**見出し → 箇条書き（入れ子）**が枝、段落・写真・表は葉、子メモは点線の枝になります。
- 枝をタップして選び、「＋子」「＋隣」「✎」「☑（チェックボックス）」「▸（折りたたみ）」「🗑」。2本指で拡大・縮小、ドラッグで移動、「⤢」で全体表示。子メモの枝は「📄」かダブルタップで開きます。
- マップで編集すると、本文が**ふつうの見出しと箇条書き**として書き換わります（Obsidian の Markmap / Mind Map プラグインでもそのまま地図になります）。
- 「いつもマインドマップで開く」にすると `view: mindmap` が付き、開くと最初からマップになります。
