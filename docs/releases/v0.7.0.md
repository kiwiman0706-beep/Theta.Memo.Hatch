# Theta Memo Hatch 0.7.0

簡易スライドを足しました。写真も入れられます。

- ⊞ →「スライド」。名前を決めると 1 枚目（表紙）の入力になります。＋ でスライドを足す、⋮ で並べ替え・複製・削除・ここから再生。
- 1 枚はタイトル・本文（箇条書き・太字など）・写真。編集中は下に仕上がりが出ます。写真は文があれば横に、写真だけなら大きく（4 枚まで並べる）。
- ▶ 再生で画面いっぱい・横向き。右側をタップかスワイプで次へ、左側で前へ。
- 本文は `---` で区切ったふつうの Markdown（Obsidian の Advanced Slides・Marp と同じ）。
- 表計算のマスにも写真を入れられるようにしました（🖼。写真のマスを押すと 変える・消す）。
