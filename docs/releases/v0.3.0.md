# Theta Memo Hatch 0.3.0（Theta Hatch シリーズへ）

- **アプリ ID が `app.thetahatch.memo` に**（以前のお試し版とは別のアプリです。お試し版はアンインストールしてください）。シリーズ共通の鍵で署名した最初の Release。
- **NAS に対応**：Synology の NAS（Tailscale 経由）に Theta Vault を置き、正本にできます。Google ドライブと両方使うときは NAS → ドライブの順に同期し、どちらで変えても揃います。2 段階認証（Secure SignIn）・自己署名の証明書に対応。Theta Home Hatch の NAS 設定を受け取れます。
- **スキン**：シリーズ共通のスキン（システム・ダーク・ライト・POP・ALERT・SCI-FI ほか）。メモの色はそのまま、スキンに合わせて明るさが変わります。
- **共通設定**：スキン・Gemini のモデル・NAS の接続先を Home Hatch・ほかのシリーズのアプリと揃えられます（`.theta/settings.json`）。Gemini API キーは Home Hatch から受け取れます。
- **更新**：アプリ自身は入れず、Home Hatch（更新のハブ）に頼みます。ハブが無ければ Releases ページを開きます。
- Obsidian 用の一覧 `Memo/メモ.base`（カード・表・GTD）を置きます。
