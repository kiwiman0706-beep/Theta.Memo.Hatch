# Theta Memo Hatch 0.6.0

簡易スプレッドシート（表計算）を足しました。

- ⊞ →「表計算」。名前を決めると、3 行 3 列の表から始まります。
- マス目にそのまま入力。Enter で下へ（最後の行なら行が増える）、Tab で右へ。
- 列の A・B… を押すと並べ替え（数字は数として）・列の挿入・移動・右寄せ・削除。行の番号を押すと行の挿入・移動・複製・削除。
- 下の段に列の合計（押すたびに 平均・最大・最小・件数）。計算した値は本文に書き込まず、ふつうの Markdown の表のままです。
- ↶ で元に戻す。ふつうのメモも「⋮」→「表計算で見る」で、最初の表を編集できます（「いつも表計算で開く」で `view: sheet`）。
