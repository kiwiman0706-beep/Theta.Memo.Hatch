# Theta Memo Hatch 0.3.5

- **撮ったものを取りこぼさない（続き）**：同期などの処理中にカメラから戻ると、受け取ったものを捨てていた不具合を直しました（順番に処理します）。戻ったときにメモの画面が閉じていても、保存したメモへ入れます。
- 端末のカメラが「OK」を返さなくても、写真が書かれていればメモに入れます。
- Camera Hatch を開けなかったときは、理由を出してから端末のカメラにします（黙って切り替えない）。
- **設定 →「カメラ連携を確かめる」**：Camera Hatch の版、撮って返す（CAPTURE）が使えるか、シリーズの権限、最近の受け渡しの記録（開いた・戻った・何件・どのメモへ）。「コピー」で貼り付けられます。
- アプリが閉じられている間に出たお知らせ・エラーも、開いたときに出します。
