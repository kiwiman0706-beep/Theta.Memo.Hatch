# Theta Memo Hatch 0.1.0（最初の版）

Google Keep の使い勝手で、データは Obsidian 形式（Theta Vault）。

- **一面に付箋を貼ったような一覧**：色付きのカード、写真・PDF・動画・手書きのサムネイル、リストのプレビュー、固定・アーカイブ・ゴミ箱、ラベル、検索（ひらがな/カタカナ同一視、種類で絞り込み）、長押しでまとめて操作、グリッド/リスト表示、ダークテーマ。
- **メモの中身**：リッチテキスト（見出し・太字・斜体・下線・取り消し線・ハイライト・箇条書き・引用・コード・リンク）、Keep式チェックリスト（チェック済みは下に、並べ替え・インデント）、表、写真（撮影・選択）、あらゆるファイル、Markdownで直接編集。
- **手書き（Sペン対応）**：筆圧、マーカー、消しゴム（サイドボタンでも）、ペン使用中は指でスクロール、再編集可。Geminiで文字に。
- **音声メモ**：録音を .m4a で残し、端末の音声認識（Android 13以降）または Gemini で書き起こし。
- **ウィジェット**：メモ一覧（テキスト・リスト・手書き・音声・写真のすばやい作成）と、1つのメモ（ホーム画面でチェック）。
- **スクラップ**：ブラウザ等の「共有」→「Theta Memoに保存」でページ・写真・PDF・ファイルを1件のメモに。URLから追加も。
- **同期**：Google Driveの `Theta Vault/Memo/`（Meishi と同じ Vault）。PC・MacはGoogleドライブ＋Obsidianで開けて、Obsidian Web Clipperの切り抜きも取り込む。
- **Google Keepから取り込み**：Google TakeoutのZIP（分割されたものもまとめて）。
- Theta Home Hatch 向けの入口（メモ一覧の提供、新規作成）。
