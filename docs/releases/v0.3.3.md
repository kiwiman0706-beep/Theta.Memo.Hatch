# Theta Memo Hatch 0.3.3

- **Theta Camera Hatch で撮る**（Camera Hatch 0.14.0 以降が入っているとき）：「写真を撮る」「スキャン」で Camera Hatch が開き、撮影画面の中で写真・動画・スキャンを切り替えて、何枚でも撮れます。「完了」で全部がそのメモに入ります（スキャンは設定に合わせて PDF かページごとの画像）。Camera Hatch のギャラリーには残りません。
- Camera Hatch が無いときは、今までどおり端末のカメラと Google のスキャナを使います。
- HEIC の写真も、メモの中ではサムネイルで表示します。
