# Theta Memo Hatch 0.4.0

マインドマップを、見ながらその場で書けるようにしました。

- 一覧の下のバーに 🧠（新しいマインドマップ）。最初からマップで、タイトルの入力から始まります。
- 枝の上で直接入力：Enter で隣の枝、Tab で下の枝、Shift+Tab で 1 段上、Esc で終わり。入力の窓は出ません。
- 枝を長押しして引っぱると移せます（相手の下・前・後ろ）。
- 💬 吹き出し、🖼 枝に写真、↗ 枝同士をつなぐ線（説明つき）、｝ 枝をまとめるかっことコメント。
- ↶ 元に戻す（Ctrl+Z）。キーボードでは矢印で枝を移動、Delete で削除。
- 本文はこれまでどおり見出しと箇条書き（吹き出しは引用、写真は埋め込み）。線とかっこは frontmatter の `map_links`・`map_groups`（[docs/GTD.md](../GTD.md)）。
