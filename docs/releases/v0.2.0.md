# Theta Memo Hatch 0.2.0

- **GTD**：受信箱・次にやる・待ち・予定・プロジェクト・いつか・資料・完了のリスト。受信箱のメモは「整理する」で質問に答えて振り分け。週次レビュー（期限切れ・次の行動が無いプロジェクトなど）。状況（@家・@PC…）、待ちの相手、期限。
- **アイゼンハワーマトリクス**：重要×緊急の4つの欄。長押しドラッグか「⇄」で移動、チェックで完了。期限が2日以内のものは自動で緊急。チェックリストの行にも ★重要・⚡緊急・📅期限（Obsidian Tasks と同じ書き方）。
- **入れ子**：子メモ（何段でも、親への道しるべ、プロジェクトの進み具合）、行から子メモを作る、親メモを選ぶ。Obsidian では `up: "[[親]]"`。箇条書き・チェックリストのアウトライン（⇥ ⇤）。
- **マインドマップ**：見出しと箇条書きを地図で表示・編集（子を追加・隣に追加・直す・チェック・折りたたみ・削除、拡大縮小）。編集は本文の見出しと箇条書きに戻ります。「いつもマインドマップで開く」も。
- 詳しくは docs/GTD.md。
