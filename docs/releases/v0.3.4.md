# Theta Memo Hatch 0.3.4

- **カメラと「選ぶ」を分けました**：一覧の下のバーに 📷（カメラが 1 回で起動）と 🖼（写真・ファイルを選ぶ）。メモの中の下のバーにも 📷 を置きました。スキャンはカメラ（Camera Hatch のスキャン）か「＋」から。
- **撮ったものを落とさない**：Camera Hatch から返ってきたものは、「完了」を押さずに戻ったときに返ってきた分も取り込みます。カメラの間に Memo が Android に閉じられても、戻ってきたら撮ったものはそのメモ（無ければ新しいメモ）に入ります。
- Home などから呼ばれたとき（`SCAN`）は、Camera Hatch があればカメラ（写真・動画・スキャン）を開きます。
