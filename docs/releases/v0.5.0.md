# Theta Memo Hatch 0.5.0

カード DB を足しました。1 つのメモが 1 つの DB で、開くとカードが並びます。

- 一覧の下のバーの ⊞ →「カード DB」（マインドマップもここに移しました）。DB の名前を決めると、最初のカードの入力になります。
- カードは名前・項目（「会社」「状態」など自由に）・メモ・写真。新しいカードには、ほかのカードの項目が最初から入ります。
- 検索、項目で並べ替え（数字は数として）、☰ で表に（見出しを押して並べ替え）。カードの複製・削除。
- 本文はふつうの Markdown：見出し 1 つがカード 1 枚、そのすぐ下の「- 項目: 値」が項目（[docs/THETA_MEMO_VAULT.md](../THETA_MEMO_VAULT.md)）。
- ふつうのメモも「⋮」→「カードで見る」で同じように見られます。「いつもカードで開く」で `view: cards`。
